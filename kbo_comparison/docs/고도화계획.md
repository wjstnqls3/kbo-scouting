# 스카우팅 플랫폼 확장 설계

## 기존 구현과 유지 범위
index.html/app.js는 선수 탐색·대상 선택·비교·CSV와 기존 간이 스카우팅을 제공한다. core.js는 집계와 추천, scouting.js는 간이 상대평가, parks.js는 구장 참고자료다. server.py는 읽기 전용 /api/players를 제공한다. 이 기능은 유지한다. 새로운 scouting-dashboard.html을 별도 연결한다.

## 데이터 점검과 가능 범위
원본 36개 열, 10,209행, 1982~2026년(2026년 296행). 선수 ID+시즌 중복 0, 서로 다른 ID의 동명이인 이름 103개, 선수별 출생일 충돌 0. Age와 Season-Born연도 불일치 1건. 원본 포지션·나이는 존재하지만 시즌별 정확성과 나이 기준일은 미확인. 빈 값과 NaN 문자열은 결측으로 처리한다. 원본 비율 대신 원자료를 합산한다.
2026년은 파일에 존재하는 것과 확정 통계임이 다르다. original_source/collected_at/season_status 미등록 상태로 확정 불가. 화면·리포트에 시즌 상태를 명시한다.

가능: 타격 대리지표·시즌별 상대평가·백분위·성장 관찰·과거 유사 유형·조건 검색.
추가 자료 필요: 실제 스윙/컨택률, 타구 속도/각도, 수비 기회와 위치, 주력 측정, 부상, 계약금액 전체, 구장별 경기 기록과 파크팩터. 저평가(가격 대비 가치)·미래 성적·성장 가능성 확률·WAR·wRC+·정식 OPS+는 산출하지 않는다.

## 개발 순서
1. 데이터 감사, 독립 analytics.js와 데이터 취득 repository.js.
2. 그래프 모듈 charts.js와 대시보드: 종합 평가 / 상대평가 / 추세 / 유사 선수.
3. 후보 발굴: 조건·생산성/성장 백분위 가중치·순위/산점도/강점과 위험.
4. 자동 리포트와 인쇄(PDF 저장), 기존 화면에 링크.
5. 수식·경계·원본 대조·화면 상태 검증. 실제 브라우저 테스트가 불가하면 한계를 기록.

## 계산 규칙
- 유효한 비투수 출전 기록을 선수 ID+시즌으로 식별. 같은 키의 복수 행은 합계/구단별 중복 여부가 불명확하므로 분석에서 제외하고 경고한다. 시즌 간 구단 변경은 해당 시즌 구단을 그대로 표시. 자동 경력 구단 대체 없음.
- AVG=H/AB, OBP=(H+BB+HBP)/(AB+BB+HBP+SF), SLG=TB/AB, OPS=OBP+SLG, ISO=SLG-AVG, BB%=BB/PA, K%=SO/PA. 분모 0은 미산출.
- 시즌 리그는 유효한 비투수 전체 원자료의 합으로 비율 재계산(최소타석 기준은 리그 합계에 미적용). 제외 건수 공개. 각 비율은 적절한 분모로 가중되며 OPS 자체를 PA로 평균하지 않는다.
- 시대 비교: OPS, ISO, BB%, K% 각각 해당 시즌 리그 값으로 나눔. 공식 구장 보정 없음. 삼진 회피=-K% 상대비, 장타=ISO 상대비, 볼넷 선택=BB% 상대비, 생산성=OPS 상대비, 안정성 대리=최근 출전 3시즌 OPS 지수 표준편차의 음수. 안정성은 3시즌 모두 최소타석 충족 필요. 안정적으로 낮은 성적도 변동 폭은 작을 수 있음.
- 백분위=100×(대상보다 낮은 값의 수+0.5×동점 수)/비교 표본 수. 대상은 비교군에서 제외. 최소 비교표본 5개, 대상 최소타석 충족 시 산출. 동률은 중간 순위. 모든 점수는 자체 점수이며 공식 스카우팅 등급이 아님.
- 비교군: 같은 시즌/전체 시대, 전체/동일 나이/동일 포지션/둘 다. 전체 시대는 선수-시즌 단위(동일 선수의 여러 시즌 포함)이며 나이 결측은 동일 나이 비교 제외. 나이 불일치는 수정 대신 미확인 처리.
- 추세: 최근 출전 3~5시즌, 연도 간격 유지. 성장률=(당해 OPS 지수/직전 연도 OPS 지수-1)×100. 전년도 출전·최소타석 미충족이면 미산출. 시즌 간 변화는 미래 예측 아님.
- 유사 선수: 대상보다 이른 기준 시즌, 대상 ID 제외, 최근 출전 3시즌 모두 최소타석 충족. 상대 ISO/BB/K/OPS와 3시즌 OPS 지수 궤적을 후보+대상 표준편차로 표준화한 RMS 거리. 분산 0인 특징 제외. 동일 후보 선수는 최소 거리 구간 하나만 남겨 TOP5. 표시 유사 점수=100/(1+거리), 확률이 아님. 궤적은 달력연도 아닌 최근 출전 시즌 순서로 정렬하고 실제 연도를 표에 제시.
- 후보 순위: 선택 시즌 전체 유효 최소타석 선수에서 생산성 백분위와 성장률 백분위를 각각 산출한 가중평균. 나이·구단·포지션 등 필터는 이 기준 모집단을 바꾸지 않는다. 가중치 0인 지표는 제외, 전부 0은 오류. 양수 가중 지표 결측 시 후보 제외. 비용 대비 저평가가 아니라 사용자가 정한 기록 조건 후보.

## 시각화 선택
Chart.js는 레이더·선·산점도와 툴팁을 제공한다(https://www.chartjs.org/docs/latest/). 현재 파일 더블클릭과 오프라인 사용을 보존하기 위해 이번 구현은 외부 다운로드 없이 SVG 차트를 사용한다. 그래프에 마우스·키보드·터치 설명, 정확한 수치 표와 인쇄 스타일 제공. 차트 함수는 계산과 분리해 추후 라이브러리 교체 가능.

## 이후 DB/API와 ML
repository.js의 load()가 records/metadata를 반환하는 계약을 유지하면 서버·DB로 교체 가능. 계산 모듈은 DOM·네트워크 의존 없음. ML은 별도 학습 데이터 검증, 시간순 학습/평가 분리, 누수 방지와 불확실성 검증 후 확장하며 이번에는 예측하지 않는다.

- 원본 대비 제외: 투수 247행, 미출전 또는 0타석 144행. 수치 오류·중복 제외 0행. 0타수이나 볼넷이 있는 행도 리그 출루율 합산에는 포함한다. 개별 분모가 0인 비율은 미산출한다.
- 나이 불일치 1건은 문기영(ID 91145), 1991년 Age=91/Born=1972-09-24이며 원본을 수정하지 않았다. 이 행은 분석용 유효 출전 집합에 들어가지 않는다.
- 계산 경계/동명이인/중복/소타석/표준화 거리/가중치와 화면 상태 테스트 추가. 상세 원본 감사 결과는 data-audit.json.
