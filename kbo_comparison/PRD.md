# KBO 타자 기록 비교 PRD

## 목표
사용자가 시즌·구단·포지션 또는 이름으로 선수를 찾고, 선택 시즌 기록을 다른 선수와 비교해 CSV로 저장한다. 최종 성적 비교 다음에 별도 스카우팅 대시보드로 이동한다.

## 구현 기능
| 영역 | 행동 | 결과 |
|---|---|---|
| 자료 정보 | 펼치기·원본 다운로드 | 출처·수집일·변환일·시즌 상태·기록 범위 표시. 미확인 값은 그대로 표시 |
| 탐색 | 시즌/전체 시즌·구단·포지션 다중 선택, 조건 배지 삭제·초기화 | 조건 적용, 이름순 10개씩, 전체 결과 정렬 |
| 최고 기록 | 기간 전체/연도별, 리그/구단 선택 | 금색/파랑/테두리로 구분 |
| 대상 | 목록 또는 이름 검색으로 추가, 기준 시즌 변경·제거 | 여러 대상의 선택 시즌 기록 표시 · 같은 선수·시즌 재선택 시 취소 |
| 추천 | 지표별 0~10 비중 적용·동일 비중 복원 | 선택한 추천 연도로 재계산 · 단일 대상 12명 또는 대상별 5명. 선수별 그룹 표시 |
| 비교 | 추천 체크·직접 검색·시즌 변경·제거 | 대상만 두 명이어도 비교. 중복 방지, CSV 저장 |

## 규칙
- 출전은 G>0. 선택한 한 시즌만 계산한다. 결측으로 계산 불가하거나 같은 선수·시즌에 여러 행이 있으면 임의 합산하지 않고 기존 선택을 유지한다.
- 선수 ID별 대상 하나를 유지한다. 기준 시즌 변경은 같은 대상의 선택 시즌을 대체한다. 비교 사례는 선수 ID+기준 시즌으로 식별한다.
- 대상 추가·제거 시 다른 비교 사례는 유지한다. 비교 사례가 대상에 추가되면 중복되는 비교 사례는 제거한다.
- 경기·타석·안타·홈런은 선택 시즌 누계. 비율은 해당 시즌의 원자료로 재계산한다.
- 기록 화면 추천 후보는 사용자가 선택한 추천 연도이며 대상 선수 자체는 제외한다. 대시보드의 유사선수는 대상 시즌보다 이전 기록 중 선수별 가장 가까운 시즌 하나만 추천한다. 대상 간 추천 중복은 허용하되 동일 선수·시즌의 비교표 추가는 한 번만 허용한다.
- 추천은 선택 지표의 차이를 후보+대상의 범위로 정규화하고 가중 평균한다. 0은 제외, 하나 이상의 양수 비중이 필요하다. 범위가 0이면 해당 지표 차이는 0이다.
- ‘선택 기간 최고’는 선택한 기간의 개별 시즌 기록끼리 비교한다. ‘연도별 최고’는 연도별로 분리한다. 구단 최고는 동일 구단 ID로 계산한다.
- 구단 검색은 시즌 소속/전체 경력 구분. 구단 최고에서는 시즌 소속 강제. 전신·후신은 검색과 집계 모두 통합하되 원래 구단명은 표에 유지한다.
- 시즌 최고의 비율 지표는 연도별 예정 경기수×3.1 버림 타석 충족자만 대상. 실제 팀 경기수 미확보 상태를 표시한다. 미달 타석 보충 예외는 적용하지 않는다.
- 최고 선수 필터·색상에서 경기 수는 제외. 비율은 원래 값으로 순위 비교. 구단·포지션 필터로 최고값의 모집단은 변경하지 않는다.
- 최종 비교표는 표시값 최고·최저를 강조하고 경기 수는 제외한다. 별도 규정 타석 기준은 적용하지 않는다.
- 필터 초기화는 탐색 조건만 기본값(최근 연도·전체 구단/포지션·이름순·기간 최고)으로 돌리며 대상·비교 선택은 유지한다.

## 저장과 데이터 한계
Python 표준 HTTP 서버의 GET /api/players는 sample_data.json을 읽는다. 메타데이터는 data_metadata.json. 두 화면은 repository.js를 공통 사용한다. 파일 직접 열기와 API 없는 정적 호스팅(404/405)에서는 동봉 자료로 열고 실제 API 장애는 숨기지 않는다. 원본 CSV에서 sync_data.py로 실행 JSON과 파일 직접 열기용 JS를 함께 재생성한다. 읽기 전용이며 선택은 메모리에만 보관한다.

원출처·수집일·시즌 완결 여부는 미확인 상태. 변환일과 수집일은 구분한다. 시즌별 포지션의 정확성, 시즌 중 이적 전후 성적, 실제 팀 경기수는 추가 검증이 필요하다. 사용자 계정·자동 수집·연봉 예측은 범위에서 제외한다.


## 확장: 스카우팅 랩
기존 기능을 유지한 별도 `scouting-dashboard.html`에서 자체 평가 대시보드, 동연령/포지션/시대별 백분위, 선택 시즌 타격 기록, 과거 유사 유형 TOP5, 조건·비중 기반 후보 발굴, 자동 리포트와 인쇄를 제공한다. 계산은 DOM과 분리하고 자료 취득 어댑터로 DB/API 교체를 준비한다.

레이더는 OBP·K%·ISO·BB%·OPS·HR%의 시즌 리그 대비 비율을 기준으로 한 자체 백분위다. 각 선수의 시즌·나이·포지션 조건으로 비교군을 구성하며 카드와 상세 리포트는 같은 계산을 쓴다. 최소타석은 비교군 선별 기준이며, 대상은 타석이 적어도 지표가 계산되고 지표별 비교 표본이 5개 이상이면 표시한다. 비교군 최소타석보다 적은 대상은 소타석 참고·점선으로 구분한다. K%만 낮을수록 높은 백분위다.

나이는 시즌 연도−출생 연도의 연 나이로 표시한다. 생일 기준 만 나이는 계산하지 않는다. 지표의 한국어 뜻을 6각형·평가표·비교 카드에 함께 적는다. 점수가 없을 때에도 6각형 외곽과 축을 유지하고 원인 및 기본 비교 조건 복원 버튼을 제공한다.

맞춤 타격 적합도는 선택 선수의 백분위 가중 평균이다. 균형은 6축 각 1, 출루 중심은 OBP 3·K% 1·BB% 2, 장타 중심은 ISO 3·OPS 1·HR% 2(나머지 0)로 설정한다. 사용자가 비중을 조정할 수 있다. 양수 비중 지표가 결측이면 점수 미산출, 0 비중은 제외, 소타석 표시는 승계한다. 소타석과 일반 기록을 자동 순위로 추천하지 않으며 선택 선수 순서를 유지한다. 중복 성격 지표가 있으므로 공식 스카우팅 점수·미래 예측·가격 가치로 해석하지 않는다.

최대 4명을 번호별로 나란히 비교한다. 선택 목록 밖 선수 검색은 단독 리포트로 전환한다. 기사 평가가 없는 선수의 의견 칸은 숨긴다. 기사 요약은 평가자를 명시하고 자체 검토 의견과 구분한다. 공개 금액은 선택 시즌에 해당하는 연봉 및 적용 기간의 계약만 표시한다. 5번의 타격 참고 등급은 200타석 이상에서 OPS 지수 기준 S≥140, A≥120, B≥110, C≥95, D≥85, E<85로 나눈다.

단독 리포트와 후보 발굴의 전년도 변화율은 양쪽 시즌의 최소타석 충족 시에만 계산한다. 3시즌 합산·성적 안정성 평가는 사용하지 않는다. 추정 wRC는 고정 공개 계수·고의4구 미분리 방식이며 공식값이 아니다. 필수 계산값이 빠지면 미산출 처리한다. wRC+는 미제공.

자체 평가임을 화면과 리포트에 표시한다. 데이터가 부족하면 평가를 보류한다. 저평가 선수의 가격 적정성, 실제 컨택률·수비·주력·부상·미래 성공 확률은 추가 데이터 없이 판단하지 않는다. 최신 검증 상태는 [전체 점검](docs/전체점검_2026-11-17.md)을 따른다. [확장 설계](docs/고도화계획.md)는 초기 계획이며 본 문서가 최신 기능 기준이다.


## 2026-11-17 화면 및 타석 기준 추가

- 자료 범위·계산 기준과 지표 산식·평균 기준은 항상 열린 두 칸. 좁은 화면에서는 위아래 배치.
- 리포트 인쇄/PDF 버튼은 리포트 맨 아래. 시작 화면 이동과 시작하기 버튼 중앙 정렬.
- 타석 카드와 시즌 기록 표에 해당 시즌의 규정타석 기준, 충족자 수, 충족자 평균 타석 표시. 기준은 기존 예정 경기 수×3.1 버림이며 실제 팀 경기 수/예외 미반영. 해당 시즌 전체 유효 타자 중 PA≥기준인 선수의 PA 합÷인원. 타격 비율의 전체 리그 평균과 별도 집계.
- 투수 포지션(P) 시즌을 기록 비교 엔진에서 제외해 이름 검색·시즌 선택·추천에도 적용. 원본 기록은 보관하며 타자로 기록된 전향 시즌은 유지.


## 외야 세부 위치

좌익수 LF·중견수 CF·우익수 RF로 분류. 원본 OF는 공식 해당 시즌 자료가 확인된 경우만 보충하며 나머지는 외야수. 동일 포지션 평가에 미확인 외야를 임의로 포함하지 않음. 기록 추천과 비교 직접 검색은 선택 연도의 포지션을 사용하며 직접 추가도 같은 연도 적용. 출처·범위·한계는 [외야 포지션 기준](docs/외야포지션_기준.md) 참조.

복수 수비 위치는 모두 표시(예: CF/RF → 중견수·우익수). 세부 자료가 없으면 외야수. 특정 위치 필터는 복수 위치 선수도 포함하며, 외야수 필터는 전체 외야를 포함합니다. 같은 선수·시즌은 비교군에서 중복 집계하지 않습니다.


## 화면 간소화 및 평가값 표시

- 추천 인원·유사도 안내 배지 제거. 1명 12개/여러 명 각 5개의 추천 계산은 유지.
- 별도 4번 스카우팅 영역 제거. 대상 1명 이상 선택하면 3번 성적 비교 제목 옆에 진입 버튼 표시. 최대 4명 제한 유지.
- 자료·평가 기준과 지표·평균 요약을 짧은 두 칸으로 표시. 상세 산식은 [별도 페이지](docs/계산기준.html)로 이동.
- 시즌 확정 정보는 자료 요약 한 곳에서 설명. 원본의 확정 여부 표기 부재이며 선수의 규정타석·평가 가능 여부와 구분.
- 평가값이 없으면 — 표시. 6각형은 비교 표본 부족, 세부 위치 자료 부족, 지표 결측을 구분. S–E 등급의 200타석 기준은 별도 유지. 규정타석 미달로 일괄 표시하지 않으며 선수 선택을 막지 않음.

추가 비교 목적: 삼진 억제는 K% 축, 볼넷은 BB% 축, 홈런은 HR% 축, OPS 중심은 OPS 축만 사용한다(해당 비중 1, 나머지 0). 기존 혼합 목적과 직접 설정을 유지한다. 적합도는 100점 만점임을 입력 영역과 결과 제목에 명시한다. 화면 명칭은 유사선수로 통일하며, 대시보드의 이전 시즌 탐색 범위는 유지한다.
