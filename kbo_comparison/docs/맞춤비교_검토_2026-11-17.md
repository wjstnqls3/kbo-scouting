# 맞춤 비교 및 그래프 점검

## 서비스 방향

[스탯티즈 공개 홈](https://en.statiz.co.kr/)에서 시즌·통산·팀 기록실, 선수 정보, 연봉 메뉴를 확인했다. 공개 메뉴 확인만으로 특정 기능이 없다고 단정하지 않는다. 기록·점수를 가져오거나 해당 서비스의 공식 지표와 일치한다고 주장하지 않는다.

이 프로젝트는 선택 선수 최대 4명의 항목별 비교, 한국어 풀이, 시즌별 리그 대비 비율, 출처가 확인된 기사·계약 정보, 사용자가 조절하는 타격 목적별 점수에 초점을 둔다. 이번에 추가한 맞춤 타격 적합도는 프로젝트의 기존 6축 백분위와 사용자 비중으로 계산한다. 스탯티즈보다 정확한 평가 또는 독점 기능이라는 의미는 아니다.

## 표시 개선

- 영문 지표 옆 한글 뜻, 최소·최대 연 나이 및 생일 미반영 안내.
- 후보 발굴 → 조건별 선수 찾기. 선수 선택 전 탐색이라는 용도를 명시.
- 6각형의 크기·선 대비 개선, 축 눈금과 한국어 설명 추가.
- 모든 점수가 없으면 틀 유지와 원인 안내. 비교 표본 부족 시 사용자가 전체 타자·동일 시즌·최소 200타석으로 되돌리는 버튼 제공. 조건을 몰래 변경하지 않음.
- 일부 값이 없으면 확인된 점만 표시. 결측값을 0으로 대체하거나 임의의 다각형을 생성하지 않음.

## 검증 및 한계

62개 자동 테스트 통과. 전체 9,818개 분석용 선수·시즌의 6축 검증 포함. 김성욱 2026년의 6개 점수와 다인 비교, 한글 표시, 비중 변경, 결측 및 실제 0점, 빈 비교군 복원 동작을 확인했다.

실제 브라우저 실행이 실패하여 화면 육안 검증은 미완료. 사용자가 본 그래프 소실 현상의 선수·필터 조건은 확인되지 않아 정확한 발생 원인은 미확정. 코드에서 확인된 빈 비교군 상태에 대한 처리와 그래프 표시를 보강했다.
