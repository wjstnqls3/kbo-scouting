# 머신러닝 실행 점검 · 일부 완료

## Python·설치·네트워크

| 환경 | Python | 설치 확인 |
|---|---|---|
| 기본 `/Library/Developer/CommandLineTools/usr/bin/python3` | 3.9.6 | numpy만 존재, pandas·sklearn·joblib·matplotlib 없음 |
| `ml/.venv/bin/python` | 3.9.6 | 이번 작업에서 생성. 패키지 설치 실패 |
| `/opt/miniconda3/envs/edu/bin/python` | 3.9.25 | pandas·sklearn·joblib·matplotlib 없음 |
| `/opt/miniconda3/envs/sports/bin/python` | 3.14.0 | pandas 3.0.6, numpy 2.5.4, matplotlib 3.11.1 존재. sklearn·joblib 없음 |
| `people_detection/.venv/bin/python` | 3.9 계열 | numpy·matplotlib 존재. pandas·sklearn·joblib 없음 |

실제로 확인한 내용:

- PyPI와 배포 파일 서버의 DNS 조회가 `gaierror [Errno 8] nodename nor servname provided, or not known`으로 실패.
- `example.com`, `github.com`도 동일 실패. localhost는 조회 가능.
- HTTPS 요청은 DNS 단계에서 실패. 패키지 다운로드나 SSL 인증서 검증까지 도달하지 못함.
- 작업 환경의 `scutil --dns`는 `No DNS configuration available` 반환.
- HTTP/HTTPS 프록시·별도 pip index 환경변수는 설정되지 않음.
- 기존 pip 캐시 쓰기 경고는 전용 가상환경과 `/private/tmp/kbo-ml-pip-cache` 지정으로 제거했으나 설치는 여전히 실패.
- 로컬 conda 환경과 패키지 캐시에서 scikit-learn·joblib 설치본을 찾지 못함.

현재 실행 세션은 네트워크가 제한되어 있다. **이 세션의 외부 DNS 실패는 확인했지만, 사용자의 일반 macOS 터미널이나 Mac 전체 네트워크까지 고장났다고 판정한 것은 아니다.** OS DNS·보안 설정은 변경하지 않았다. 패키지 버전 충돌을 해결한 것처럼 보고하지 않는다.

## 실제 수행

1. 머신러닝 전용 `.venv` 생성 및 캐시 위치 수정 후 설치 재시도 → 실패.
2. 데이터 검사와 sklearn 모델 가져오기를 분리.
3. 기존 sports 환경으로 데이터·성능 산식·보고서 무결성 테스트 실행: **9개 통과 / 학습 테스트 1개 건너뜀**.
4. 기존 웹서비스 JavaScript 테스트 **62개 통과**.
5. 실제 CSV에서 2025년까지 읽어 입력 시즌 100타석 이상 조건으로 정확한 연속 시즌 쌍 검증.
6. 전년도 홈런 수 유지 기준선 실행 및 PNG·PDF·HTML 보고서 생성. 그래프의 한글 표시와 배치를 이미지로 확인.

## 실제 기준선 결과

Random Forest 결과가 아니라, 학습 없는 **전년도 홈런 수 유지 예측** 결과다. 실제값은 동봉 CSV 기준이며 외부 공식 기록과 다시 대조한 것은 아니다.

| 2023 | 134 | 3.7985 | 5.6654 | 0.1740 |
| 2024 | 141 | 4.4681 | 6.8799 | 0.4394 |

| 합산 | 406 | 4.4064 | 6.8245 | 0.3005 |

분석 가능 연속 시즌 쌍 4,549개. 다음 시즌 행이 없는 507개는 0홈런으로 만들지 않고 제외. 2026년 행 296개는 모든 입력·정답에서 제외. 2025년 기준 향후 예측 대상 후보 155명. 후보에게 모델 예측값을 생성한 것은 아니다.

## 실행하지 못한 작업

- scikit-learn·joblib 설치.
- Random Forest 통합 테스트 및 실제 CSV 학습.
- Random Forest 예측 홈런, MAE·RMSE·R² 및 기준선 대비 개선율 계산.
- 미래 시즌 선수별 모델 예측과 학습 모델 파일 생성.

이유는 패키지 다운로드에 필요한 현재 실행 환경의 외부 DNS/네트워크 접근 불가. 모델 결과를 다른 알고리즘이나 기준선 값으로 대체하지 않았다.

## 이어서 실행

일반 macOS 터미널에서 `jeonsubb` 폴더 기준:

```sh
zsh kbo_comparison/ml/install_and_train.command 2025
```

검토 가능한 실행 파일에 설치 → 필수 import 확인 → 전체 테스트 → Random Forest 학습·연도순 검증 → 시각화 순서를 작성했다. 앞 단계가 실패하면 다음 단계는 실행하지 않는다. 새 결과 폴더에 실행 로그와 설치 버전을 보관한다. 이 명령을 일반 터미널에서 실행한 결과는 아직 확인하지 못했다.

이번 수정은 `ml/`와 프로젝트 README 안내에 한정했으며 기존 선수 비교 화면과 원본 CSV는 수정하지 않았다.
