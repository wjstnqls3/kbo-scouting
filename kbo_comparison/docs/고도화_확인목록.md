# 사용자 화면 확인 목록

자동 확인: 기존 기능 및 새 계산/화면 상태 테스트. 미확인: 실제 브라우저 렌더링·터치·인쇄. 아래 항목은 사용자 환경에서 확인할 시나리오다.

1. index.html의 시작 버튼과 문 열기 → 기존 탐색/대상 추가/CSV가 정상인지 확인.
2. ‘스카우팅 랩’ → 선수별 레이더·백분위·상대 지수, 2026 미확인 안내 확인.
3. 2022년 이정후(ID 67341) 선택 → 동일 나이 비교의 작은 표본과 미산출 표시 확인.
4. 동일 포지션/전체 시대, 3→5시즌 전환 → 그래프와 표의 실제 연도/모집단이 변경되는지 확인.
5. 최소타석 1000 입력 → 점수 보류, 그래프에 가짜 0점이 생기지 않는지 확인.
6. 검색 결과 없는 이름 → 결과 없음. 다른 선수 선택 후 정확한 ID·시즌 구단 확인.
7. 그래프 점과 막대에 마우스/키보드 Tab/터치 → 수치와 뜻. Esc로 툴팁 닫기.
8. 후보 발굴: 나이·시즌·구단·포지션 변경, 비중 전체 0 오류, 성장 비중 0일 때 전년도 없는 선수 허용 확인.
9. 후보 ‘보기’ → 동일 선수/시즌 리포트로 이동 확인.
10. 375px 모바일 폭에서 필터·차트·카드가 화면 안에 들어오는지, 넓은 표는 표 영역만 가로로 움직이는지 확인.
11. 인쇄/PDF → 현재 선수·기준·그래프·표·한계 안내가 나오고 후보 검색 화면은 제외되는지 확인.
12. 인터넷 없이 파일 직접 열기 및 server.py로 열기에서 같은 데이터 결과 확인.
