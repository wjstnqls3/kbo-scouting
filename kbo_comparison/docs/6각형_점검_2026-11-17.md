# 6각형 평가 표시 점검

- 원인: 대상 선수가 설정한 최소타석보다 적으면 계산 가능한 6개 점수까지 모두 숨기던 조건.
- 예시: 보유 자료의 2026 SSG 김성욱은 142타석. 기본 비교군은 같은 시즌·200타석 이상·본인 제외 111명. 6개 지표 계산 가능.
- 수정: 최소타석은 비교군 선별에 적용. 대상은 지표와 비교 표본이 있으면 백분위 표시. 타석이 기준보다 적으면 ‘소타석 참고’와 점선 표시.
- 결측: 지표별 표본 5개 미만, 원기록으로 계산 불가, 확인된 나이·포지션 비교 불가 시 해당 점수는 —. 임의의 0점으로 대체하지 않음.
- 범위: S–E 등급, 성장률, 과거 유사선수의 타석 조건은 별도 유지.

## 검증

- 분석용 9,818개 선수·시즌의 6개 축을 원기록 비율과 직접 산출한 백분위로 대조.
- 기본 조건에서 9,804개 선수·시즌은 6축 모두 계산 가능. 이 중 5,884개는 200타석 미만으로 이전에 숨겨지던 사례.
- 나머지 14개는 일부 지표 계산 불가. 계산 가능한 축만 표시.
- 김성욱 단독·다인 비교의 6개 점수, 점선, 소타석 표시 및 상단/상세 값 일치 확인.
- 자동 테스트 58개 통과. 실제 브라우저 육안 확인은 미실시.
- 원본 CSV와 실행 JSON·해시 일치. 선수·시즌 13개 지표와 45시즌 리그 합산 독립 계산 일치.
- 검증 대상은 프로젝트 보유 자료. 2026년 원자료의 최종 확정 여부를 새로 확인한 것은 아님.
