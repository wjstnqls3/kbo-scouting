# 인수 확인표

계산 8개·화면 상태/이벤트 3개·HTTP 핸들러 3개 테스트 통과. 화면 상태 테스트는 DOM 모의 환경입니다. 아래 브라우저 시나리오는 실제 화면 검증 필요.

| 내가 할 행동 | 기대 결과 |
|---|---|
| 2022·2023 선택, 구단·포지션 다중 선택 | 선택 조건에 맞는 시즌별 기록과 제거 가능한 배지 표시 |
| 조건 배지 × 클릭 | 해당 조건만 제거. 마지막 연도 제거 시 기본 최근 연도로 복원 |
| 필터 초기화 | 최근 연도·전체 구단/포지션·이름순·기간 최고로 복원. 대상 선택 유지 |
| 목록에서 더 보기·열 제목 클릭 | 10개씩 확대. 전체 결과 정렬 후 처음 10개 표시 |
| 두 연도 선택 후 최고 기준 변경 | 선택 기간 전체 최고 / 각 연도 최고를 구분 |
| 전체 시즌·SK/SSG·구단 최고 | 하나의 구단으로 통합한 최고값. 원래 구단명은 표시 |
| 리그 최고·구단 최고 확인 | 금색/파랑, 둘 다면 금색+파란 테두리. 경기 수 제외 |
| 144경기 시즌의 445/446타석 확인 | 비율 최고 후보에서 445 제외, 446 포함 |
| 경력 구단 후 구단 최고 선택 | 시즌 소속 기준으로 전환, 경력 선택 비활성화 |
| 2018 미출전 선수의 2019 기준 추가 | 2019·2017·2016처럼 실제 최근 출전 세 시즌 사용 |
| 대상 두 명만 추가 | 비교표와 CSV 활성화. 추천 선수를 추가할 필요 없음 |
| 대상 하나/여러 명 확인 | 추천 최대 12명 / 각 대상별 최대 5명. 개별 그룹 표시 |
| 홈런 비중만 양수로 적용 | 홈런 기록 차이를 기준으로 추천. 다른 선택은 유지 |
| 모든 비중을 0으로 적용 | 오류 안내. 이전 비중과 추천 유지 |
| 0~10 밖의 값 입력 | 입력 제한 또는 오류 표시 |
| 동일 비중 클릭 | 모든 지표 비중 1로 복원 |
| 기록 부족 대상 추가·시즌 변경 | 기존 대상과 비교표를 유지하고 별도 오류 안내 |
| 추천 체크 후 같은 선수·시즌을 직접 추가 | 중복 행 없이 안내. 동일 추천의 체크 상태 일치 |
| 비교 시즌을 이미 있는 구간으로 변경 | 기존 선택 유지, 중복 안내 |
| 새로운 대상 추가·제거 | 다른 비교 사례 유지. 대상과 겹치는 비교 선수는 제외 |
| CSV 다운로드 | 실제 대상·비교 선수, 실제 합산 연도, 지표 저장 |
| 자료 정보 열기 | 출처·수집일·완결 여부 미확인 표시, 변환일은 별도 표시 |
