# 외야 포지션 분류 · 2026-11-17

## 표시

- LF: 좌익수
- CF: 중견수
- RF: 우익수
- 복수 위치: 확인된 위치 모두 표시. 예: CF/RF → 중견수·우익수.
- OF: 외야수. 세부 위치 자료가 없는 경우의 화면 표시. 별도의 미확인 표시는 붙이지 않음.

원본 CSV의 외야 기록 3,614개는 모두 OF다. 원본을 변경하지 않고 `position-data.js`의 선수 식별자·시즌·이름·구단이 모두 일치하는 23개 기록에 확인된 위치를 보충했다. 나머지 3,591개 원본 기록은 외야수로 표시한다. 과거 또는 다음 시즌으로 분류를 복사하지 않는다.

## 분석 및 오류 수정

- 기록 목록, 추천 목록, 직접 검색, 후보 발굴, 과거 유사선수, 리포트가 공통 포지션 분류를 사용한다.
- 추천 포지션 조건은 전체 경력 포지션이 아니라 **선택한 추천 시즌의 포지션**에 적용한다.
- 비교 선수 직접 추가도 선택한 추천 연도를 사용한다. 이전에는 최신 유효 시즌을 사용해 검색 조건과 실제 추가 시즌이 달랐다.
- 동일 포지션 비교는 확인된 위치가 하나 이상 겹치는 선수를 포함한다. 예를 들어 CF/RF 선수는 CF 또는 RF 기록과 비교하며, 양쪽 조건에 해당해도 한 번만 집계한다. 세부 자료가 없는 OF는 좌·중·우 비교군에 임의 배정하지 않고 미산출 처리한다. 전체 타자·동일 나이 비교에서는 기록을 유지한다.
- 필터의 ‘외야수’는 LF·CF·RF·OF를 모두 포함한다. 특정 위치를 선택하면 그 위치가 확인된 단일·복수 위치 선수만 포함한다.
- 표본 5개 미만이면 백분위 미산출. 확인 자료가 일부 수비상 후보·수상자에 한정되므로, 표본이 충분해도 전체 외야수의 대표 분포로 해석하면 안 된다.
- 상세 리포트에 해당 시즌의 포지션 근거 링크 표시. 더 많은 시즌을 정확히 분류하려면 선수·시즌별 수비 위치 및 이닝 자료가 필요하다.

## 검증

JavaScript 테스트 52개 통과. 실제 확인 기록의 식별자·이름·시즌·구단 대조, 원본 불변, 다른 시즌/구단으로 분류 전파 방지, 미확인 외야의 동일 포지션 평가 제외, 시즌별 추천 조건, 직접 추가 연도를 검증했다. 원본 CSV와 9,818개 선수·시즌의 타격 지표 대조도 유지된다. 실제 브라우저 레이아웃 검증은 미실시.
