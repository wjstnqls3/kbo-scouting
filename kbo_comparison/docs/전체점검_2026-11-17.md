## 검증 결과

- JavaScript 테스트 **43개 통과**. 시작 시 36개 중 6개는 예전 기능을 전제로 실패했으며, 현재 요구에 맞게 갱신하고 회귀 검증을 추가했다.
- HTTP 핸들러 테스트 **3개 통과**: 선수 API, 메타데이터 응답, 원본 읽기 실패 처리.
- CSV와 실행 JSON의 모든 필드 및 원본 해시 일치. 파일 직접 열기용 data.js와 JSON 일치.
- 분석 대상 **9,818개 선수·시즌**, **45개 시즌**의 합산 리그 값 독립 계산 일치.
- 대조 지표 13개: PA, AVG, OBP, SLG, OPS, ISO, BB%, K%, HR%, wOBA, OPS 지수, 추정 wRC, 100타석당 추정 wRC.
- 실제 데이터에서 투수 247행, 미출전/0타석 144행 제외. 현재 분석 검증 규칙상 수치 오류·중복 선수/시즌 행 0건.
- 주요 두 HTML의 중복 ID 없음. 참조된 스크립트·스타일·이미지 파일 존재. 전체 JavaScript 문법 확인.
- 화면 상태 검증은 DOM 모의 환경. 실제 브라우저의 애니메이션·모바일 배치·PDF 페이지 분할은 직접 검증하지 못함.

## 남아 있는 자료 한계

- 원출처·수집일·시즌 확정 상태는 메타데이터에 없음. **2026년 최종 확정 기록 여부 미확인**. 계산 일치는 원본의 사실 정확성이나 완결성을 보증하지 않음.
- 분석 대상 선수 1,878명 중 공개 연봉 또는 적용 계약이 등록된 선수는 **10명, 52개 선수·시즌**. 기사 평가가 등록된 경우는 **6명, 6개 선수·시즌**. 이번 점검에서 기사·계약 자료를 추가 수집하지 않음.
- 리그 평균은 보유한 유효 비투수 원자료를 합산해 계산. 규정타석 이상 선수만 평균 내는 방식이 아님. 실제 공식 리그 집계와는 자료 범위가 다를 수 있음.
- 시즌별 포지션 정확성과 시즌 중 이적 전후 성적 분리는 별도 확인 필요. 동명이인 구분용 내부 식별자는 유지하고 화면에서는 숨김.
- 추정 wRC는 고정 선형가중치, 고의4구 미분리 방식. 공식값·wRC+가 아님. [FanGraphs wRC 산식](https://library.fangraphs.com/offense/wrc/)과 [야구나라 공개 계수](https://www.yagoonara.com/guide/formulas/constants)를 확인했으며 기존 계수는 유지했다. 정확한 시대별 추정에는 시즌별 계수와 고의4구 자료가 필요함.
- 가격 대비 저평가, 수비·실제 컨택률·부상 위험·미래 성적은 현재 자료만으로 판단하지 않음.
