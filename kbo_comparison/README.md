# KBO 타자 스카우팅 포트폴리오

스카우팅 분석가가 필요한 타자 유형을 정하고, 시즌 기록으로 검토 후보를 좁힌 뒤, 후보 간 차이와 영상·현장 관찰 메모를 한 문서로 남기는 프로젝트입니다. 스카우팅 담당자는 1차 검토 후보를 선별할 때, 에이전트 지망생은 선수별 관찰 근거를 정리할 때 사용할 수 있습니다. 기록 조회 서비스를 활용하는 분석 과정 중 **목적 설정 → 후보 탐색 → 비교 → 해석 → 보고서 작성**에 초점을 둡니다.

## 실행 방법

프로젝트 폴더 전체를 내려받고 `index.html`을 여세요. 메모 저장에 일정한 브라우저 주소를 사용하려면 프로젝트 상위 폴더에서 아래 명령을 실행한 후 `http://localhost:8000`으로 접속하세요. Python 외 별도 패키지는 필요하지 않습니다. 파일 직접 열기의 저장 지원은 브라우저에 따라 달라집니다.

```bash
python3 kbo_comparison/server.py
```

정적 호스팅에서 API가 404 또는 405를 반환하면 동봉 데이터를 사용합니다. API 장애는 화면에 표시합니다.

## 화면 선택

**스카우팅 검토**는 필요한 타자 유형을 정하고 후보를 비교해 보고서를 작성하는 화면입니다. **스카우팅 랩**은 관심 선수의 백분위·시각화·유사 선수·공개 계약 자료를 자세히 살펴보는 화면입니다. 시작 화면과 기록 비교에서 두 화면 모두 바로 열 수 있습니다. 검토 보고서에서 랩으로 이동하면 선택한 후보와 시즌을 함께 가져갑니다.

## 포트폴리오 시연 순서

1. 시작 화면에서 **스카우팅 검토 후보 찾기**를 엽니다. 예를 들어 2024년, 전체 포지션, 200타석, 출루형을 설정합니다.
2. **스카우팅 검토 후보 찾기**를 눌러 순위, 타석, 선택 지표의 실제 기록과 백분위, 추가 확인 사항을 확인합니다.
3. 후보 2~3명을 선택합니다. 아래 보고서에서 목적별 지표 차이와 최근 최대 5개 시즌의 타석·OBP·SLG·OPS·리그 대비 OPS를 확인합니다. 기존 기록 비교·CSV와 스카우팅 랩은 같은 선수와 시즌을 새 탭으로 엽니다. 기존 랩은 자체 비교군과 적합도 설정을 사용합니다.
4. 분석가 메모를 입력하면 이 브라우저에 자동 저장되며 저장 결과가 입력칸 아래에 표시됩니다. 같은 브라우저와 주소에서 해당 선수·시즌을 다시 선택하면 메모가 복원됩니다. 서버 계정이나 기기 간 동기화는 제공하지 않습니다. 탐색 조건과 후보 선택은 재접속 시 다시 설정합니다.
5. **보고서 인쇄 / PDF 저장**에서 브라우저 PDF 저장을 선택합니다. 인쇄용 화면은 입력란과 조작 버튼을 숨기고 메모를 본문에 표시합니다. 기본 머리글·바닥글은 인쇄 대화상자에서 설정합니다.
6. **비중 변경에 따른 순위 변화**에서 다른 유형을 선택해 두 기준의 점수·순위·변화 기여도를 확인합니다. 두 기준에 필요한 지표가 모두 유효한 공통 비교군에서 양쪽 순위를 다시 계산하므로 결측이 있을 때 최초 탐색 순위와 달라질 수 있습니다.

## 후보 점수와 데이터 해석

| 유형 | 기본 비중 |
| --- | --- |
| 출루형 | OBP 3 · BB% 2 · K% 1 |
| 장타형 | ISO 3 · HR% 2 · OPS 1 |
| 콘택트형 | K% 4 · OBP 1 |
| 균형형 | OBP·K%·ISO·BB%·HR% 각 1 |
| 사용자 지정 | 지표마다 0~10 · 0은 제외 |

같은 시즌·포지션·최소 타석을 충족한 기록에서 지표별 백분위를 계산합니다. 백분위는 `100 × (낮은 값 수 + 동률 수 / 2) ÷ 유효 기록 수`이며 본인을 포함합니다. K%는 방향을 뒤집습니다. 참고 적합도는 백분위에 비중을 곱해 더한 뒤 비중 합계로 나눈 값입니다. 비중이 양수인 지표 중 유효 기록이 5명 미만이거나 선수 값이 결측이면 판단을 보류합니다. 동점은 같은 순위이며 화면에서는 타석, 이름, ID 순으로 표시합니다. OPS와 OBP, ISO와 HR%처럼 관련된 지표에 동시에 비중을 주면 같은 성과가 점수에 여러 번 반영될 수 있습니다. K%는 콘택트의 참고 지표이며 스윙당 콘택트율 자료는 없습니다.

- 타율은 H/AB, 출루율은 (H+BB+HBP)/(AB+BB+HBP+SF), 장타율은 TB/AB, OPS는 OBP+SLG, ISO는 SLG−AVG입니다. BB%, K%, HR%는 각각 BB, SO, HR을 PA로 나눕니다. BB/K는 BB를 SO로 나눕니다. 분모가 0이거나 필수 기록이 비어 있으면 해당 값은 미산출입니다.
- 리그 대비 OPS는 선수 OPS를 시즌 합산 OPS로 나눈 뒤 100을 곱합니다. 시즌 합산 OPS는 보유 타자 기록의 분자·분모를 합산해서 계산합니다. 새 후보 화면의 백분위는 고정된 동일 시즌 비교군을 사용합니다.
- 최소 타석은 사용자가 고르는 검토 표본 기준입니다. 별도로 표시하는 규정 타석 참고값은 예정 팀 경기수 × 3.1의 소수점 버림을 사용합니다. 실제 팀 경기수 차이·시즌 중간 진행도·미달 타석 보충 예외는 반영하지 않습니다.
- 순위 변화는 같은 공통 비교군의 백분위에서 발생한 가중치 차이입니다. 변화 기여도는 각 지표 백분위에서 50을 뺀 뒤, 정규화한 비중의 변화량을 곱해 계산합니다.

## 데이터 범위와 제출 전 확인

- 동봉 CSV는 1982~2026년 10,209행입니다. 분석 엔진은 투수 표기 247행과 경기 또는 타석이 0인 144행을 제외한 9,818행을 사용합니다. 원본에는 ID·선수명·생년월일·시즌·구단·포지션·선수 URL·경력·드래프트·타격 집계 등이 있습니다. 선수 URL은 KBO 페이지를 가리키지만 데이터셋의 원 수집처·수집일과 2026년의 최종 확정 여부는 메타데이터상 미확인입니다.
- 같은 선수 ID와 시즌을 기록 키로 사용합니다. 구단이 달라도 같은 ID의 기록을 연결하고 동명이인을 이름으로 합치지 않습니다. 중복 시즌 행은 분석에서 제외하고 같은 ID에서 출생 정보가 충돌하면 추이 연결을 보류합니다. 시즌 추이 표는 원자료 부재, 원자료는 있으나 분석 제외, 값이 0인 경우를 구분합니다.
- 외야 세부 위치는 [확인된 보충 자료](docs/외야포지션_기준.md)가 있는 시즌에만 적용합니다. 포지션은 수비 실력이나 출전 비중을 뜻하지 않습니다. 기존 랩의 나이는 연 나이이며 생년과 일치하는지 점검합니다. 일부 연봉과 계약은 기존 랩에 KBO 공지·구단·보도 링크와 함께 표시합니다. 실시간 계약 상태나 이적 가능성은 평가 범위 밖입니다.
- 파크팩터·연령·시즌 환경 보정은 새 참고 적합도에 적용하지 않습니다. 수비 능력·주력·부상 이력·시장가치·미래 성적은 이 보고서의 평가 범위 밖입니다.
- 제출 전 선수 사진과 구단 로고의 원본 출처와 공개 사용 권한, 원자료의 재배포 조건을 별도로 확인하세요. 실제 브라우저에서 좁은 화면의 표 가로 스크롤, 긴 메모의 인쇄 줄바꿈, PDF 페이지 경계와 실제 CSV 저장도 확인하세요.
- 향후에는 시즌 마감 상태와 데이터 수집 이력 관리, 포지션별 수비 이닝 보강, 검토 조건을 포함한 보고서 초안 재현을 개선할 수 있습니다.

## 기존 기록 비교 사용법

1. 시즌·구단·포지션 선택 → 이름순 목록, 열 제목으로 정렬, 10개씩 더 보기.
2. 선수의 ‘대상 추가’ → 선택한 한 시즌의 기록 표시. 같은 선수·시즌을 다시 누르면 취소. 대상 두 명만으로도 비교·CSV 저장 가능.
3. 추천 연도를 선택하면 그 연도 기록으로 재계산. 한 명은 최대 12명, 여러 명은 각 최대 5명 추천. 지표·비중에서 0은 제외, 1~10은 상대 비중. ‘적용’으로 갱신.
4. 추천 체크 또는 직접 검색 → 비교표. 선수·기준 시즌이 같으면 중복 추가하지 않음.

## 기준

- 최고 기록: ‘선택 기간 최고’ 또는 ‘연도별 최고’. 전자는 선택한 모든 연도의 개별 시즌 기록 중 최고이며, 여러 시즌을 합산한 순위가 아닙니다.
- 리그 최고 금색, 구단 최고 파랑, 둘 다 금색+파란 테두리. 경기 수는 강조와 최고 선수 필터에서 제외.
- 구단별 최고는 전신·후신을 묶은 구단 ID와 기록 당시 소속으로 계산. 현대 계열과 히어로즈 계열은 별개.
- 경력 구단 검색은 해당 시즌 소속·이적 사실을 뜻하지 않음. 원본은 시즌 중 이적 전후 성적을 분리하지 않을 수 있음.
- 타율·출루율·장타율의 시즌 최고는 `floor(연도별 예정 팀 경기수 × 3.1)` 타석 충족자만 계산. 144경기는 446타석. 실제 팀 경기수 차이·시즌 중간·미달 타석 보충 예외는 반영하지 않음.
- 최종 성적 비교는 각 선수의 선택 시즌 원자료로 계산하며 별도 규정 타석 제한 없음. 표시값 최고 빨강, 최저 파랑, 전부 같으면 두 색. 경기 수 제외.
- 추천 지표별 차이를 후보+대상의 범위로 나눈 뒤 설정한 비중으로 평균. 선택 연도의 기록 유사도이며 미래 성적·가치 예측이 아님. 스카우팅 대시보드의 유사선수는 별도로 이전 시즌만 탐색.

## 데이터 갱신

원본: 같은 폴더의 `kbo_batting_stats_season_1982-2026.csv`.

```bash
python3 kbo_comparison/sync_data.py
```

이 명령은 원본 CSV에서 sample_data.json, data.js, data_metadata.json, metadata.js를 함께 갱신합니다. 직접 JSON을 편집하면 파일 직접 열기와 결과가 달라질 수 있으므로 원본 CSV를 수정하고 동기화하세요.

`data_metadata.json`의 original_source·collected_at·season_status는 확인한 사실만 입력하세요. 기본값은 미확인입니다. packaged_at은 변환일이며 수집일이 아닙니다. season_status는 연도를 키로 하고 ‘완료’, ‘진행 중’, ‘미확인’ 같은 문구를 값으로 사용합니다. 메타데이터를 변경한 뒤에도 sync_data.py를 실행해 파일 직접 열기용 자료를 갱신하세요.

API: GET /api/players → JSON 배열. 메타데이터: /data_metadata.json. 읽기 전용이며 새로고침하면 사용자 선택이 초기화됩니다.

## 기존 스카우팅 랩

개인 및 선택 선수 비교 레이더는 AVG(H/AB), BB%(BB/PA), K%(SO/PA), ISO(SLG−AVG), SB/PA의 다섯 축을 사용합니다. 동일 시즌 200타석 이상 타자 중 지표별 유효 기록을 기준으로 중간 순위 백분위를 계산합니다. K%는 값이 낮을수록 유리합니다. 포지션 모드는 확인된 세부 위치가 하나 이상 겹치는 타자로 비교군을 좁힙니다. 축별 유효 표본 5명 미만, 결측, 계산 불가를 구분하며 실제 기록과 백분위의 차이를 각각 표시합니다. 개인 참고 등급은 같은 다섯 축의 평균을 사용합니다. 등급표의 **이 시즌 등급별 선수 보기** 또는 **조건별 선수 찾기**에서 시즌과 S~E 등급을 골라 선수 상세를 열 수 있습니다. 맞춤 적합도도 같은 다섯 축의 백분위에 사용자가 설정한 비중을 적용합니다.

기존 랩의 선수 평가 기준은 선택 시즌 하나입니다. 스카우팅 랩에서 동연령·포지션 비교, 리그 대비 OPS 지수, 유사선수를 확인합니다. 3시즌 합산과 성적 안정성 평가는 사용하지 않습니다. 이전의 [분석 기능 설계](분석기능_설계.md)는 초기 설계이며 최신 기준은 [PRD](PRD.md)를 따릅니다. 스카우팅 검토의 200타석은 후보 탐색 시작값입니다. 스카우팅 랩의 기본 비교 기준은 시즌별 규정 타석 참고값입니다.


## 스카우팅 랩 (확장 화면)

대상 선수 1명 이상 선택하면 `3. 최종 성적 비교` 제목 옆에 스카우팅 분석 버튼이 나타납니다. 별도의 4번 영역은 없습니다. 버튼을 누르면 스카우팅 전용 화면으로 이동합니다. 화면 왼쪽 위에서 애니메이션 시작 화면이나 기록 비교로 돌아갈 수 있습니다. 선수 번호는 화면에 표시하지 않습니다. 동명이인 구분을 위해 데이터 내부에서는 번호를 사용합니다.

- 선수 대시보드: 시즌·이름·비교 시대/집단·최소 타석 설정 → OBP·K%·ISO·BB%·OPS·HR%의 6축 자체 백분위, 분포 산점도, 리그 대비 그래프, 선택 시즌 기록, 유사선수 TOP 5, 기사 의견·계약 리포트.
- 최대 4명. 번호별로 선수들을 나란히 비교합니다. 각 선수의 조건으로 비교군을 계산하므로 선택 순서가 바뀌어도 점수는 유지됩니다. 목록 밖의 선수 검색은 단독 리포트로 표시하며 상단 선택 버튼으로 비교에 복귀합니다.
- 선택 시즌의 등록된 기사 평가가 없으면 해당 의견 칸을 숨깁니다. 공개 금액은 확인된 연봉과 적용 계약만 표시하며 계약 총액을 연봉으로 나누지 않습니다.
- 후보 발굴: 나이·시즌·구단·포지션·최소타석·상대 OPS·성장률 조건, 생산성/성장 비중 조절. 후보의 ‘보기’로 상세 리포트 이동.
- ‘리포트 인쇄 / PDF 저장’은 브라우저 인쇄 창을 엽니다. 실제 PDF 레이아웃은 사용자 환경에서 확인하세요.
- 차트 수치는 마우스·키보드·터치로 확인합니다. 표본 부족은 미산출입니다. 외부 연결 없이 동작합니다.
- `repository.js`: 자료 취득, `analytics.js`: 순수 계산, `charts.js`: SVG 그리기, `dashboard.js`: 화면 상태, `dashboard.css`: 반응형/인쇄 스타일.
- [고도화 설계 및 수식](docs/고도화계획.md), [원본 감사 결과](docs/data-audit.json), [수동 확인 목록](docs/고도화_확인목록.md).

추가 검증: `PYTHONDONTWRITEBYTECODE=1 python3 kbo_comparison/tests/audit_csv.py`. 원본과 실행 데이터가 다르면 대조가 실패합니다. 2026년을 포함한 시즌 상태는 메타데이터에서 확인된 값만 사용하며 현재 2026년 최종 확정 여부는 미확인입니다.


외야 세부 위치: `position-data.js`에서 공식 자료와 일치하는 시즌만 LF·CF·RF로 보충합니다. 원본 CSV는 유지합니다. 확인되지 않은 OF는 ‘외야수’으로 표시하며, 동일 포지션 평가에서는 미산출합니다. [분류 근거와 적용 범위](docs/외야포지션_기준.md). 비교 선수 검색·추가 및 추천 필터는 선택한 추천 연도의 기록을 기준으로 합니다.

복수 수비 위치는 모두 표시(예: CF/RF → 중견수·우익수). 세부 자료가 없으면 외야수. 특정 위치 필터는 복수 위치 선수도 포함하며, 외야수 필터는 전체 외야를 포함합니다. 같은 선수·시즌은 비교군에서 중복 집계하지 않습니다.

- 레이더 비교군은 동일 시즌 200타석 이상입니다. 랩의 리그 평균은 규정 타석 참고값 충족 기록만 합산합니다. 대상이 200타석 미만이면 유효한 백분위를 긴 점선으로 표시합니다. 지표별 비교 표본이 5개 미만이면 —로 표시합니다. S–E 참고 등급은 5각형의 다섯 백분위 평균이며, 규정 타석 참고값과 설정 최소 타석 중 높은 기준을 충족해야 합니다.

- 자체 평가의 영문 지표에 한글 뜻 병기: OBP 출루율, K% 삼진율, ISO 순장타율, BB% 볼넷률, OPS 출루율+장타율, HR% 홈런율.
- 나이는 연 나이(시즌 연도−출생 연도). 생일을 반영한 만 나이가 아니며 입력란·선수 정보·비교 집단에 명시.
- ‘후보 발굴’ 탭은 ‘조건별 선수 찾기’로 표시. 비교할 선수를 아직 정하지 않은 경우에 사용하는 선택 기능.
- 맞춤 타격 적합도: 균형·출루 중심·장타 중심·직접 설정. 선택 선수의 5각형 레이더 지표별 백분위를 설정한 비중으로 가중 평균. 공식 지표·성공 확률이 아니며 비교 집단별 상대 순위라는 제한을 표시. 계산은 `analytics.fitScore`로 분리.
- 5각형 외곽·축은 점수 결측에도 표시. 표본 부족 원인과 기본 비교 조건으로 돌아가는 버튼 제공. 구형 파일 혼용 방지를 위해 변경한 대시보드 자산에 버전 표시.

- 맞춤 목적 추가: 삼진 억제(K%가 낮을수록 높은 백분위), 볼넷(BB%), 홈런(HR%), OPS 중심. 각각 해당 축만 비중 1, 나머지 0. 적합도는 100점 만점의 가중 평균이며 성공 확률 또는 전체 선수 중 종합 순위가 아님.
